## ✨ Features

- ⚡ **Lightning Fast:** Built on Vite and React 19 for instantaneous load times and smooth client-side routing.
- 🎨 **Modern Dark Aesthetics:** Sleek dark mode design with vibrant accents, custom typography, and glassmorphism.
- 🎬 **Fluid Animations:** Engaging micro-interactions, scroll-driven parallax effects, and animated marquees powered by Framer Motion.
- 📂 **Interactive Project Showcase:** Highlighting real-world projects, client websites, and interactive Figma prototypes.
- 📄 **CV / Resume Download:** Direct access to download latest UI/UX and Software Engineering resume.
- 📱 **Fully Responsive:** Perfectly optimized for desktops, tablets, and mobile devices.
- 🌐 **SEO Optimized:** Structured JSON-LD metadata, OpenGraph tags, sitemap, and robots.txt.

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18.0.0 or higher recommended)
- **npm** or **yarn** / **pnpm**

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/M-Taqi796/Muhammad-Taqi-Portfolio.git
   cd Muhammad-Taqi-Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the local development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the site.

### Building for Production

To create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

### Deployment

Deploy to GitHub Pages:

```bash
npm run deploy
```
